# Developer Portfolio (React + Vite)

## Run locally
1. Install Node.js (18+ recommended).
2. In this folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL printed by Vite.

## Customize
- Edit the profile copy and links in `src/App.jsx`.
- Replace the project image URLs in the `projects` array.
- Put your CV PDF at `public/cv.pdf` so the Download CV link works.
- Replace the email and social links with your own.
